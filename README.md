# Battle Blasters

A tank battle game built in Unreal Engine 5.8, featuring independently controlled hull, turret, and barrel rotation for realistic tank combat mechanics.

## Features

- Independent hull, turret, and barrel rotation system
- Tank controller implemented in C++
- Built and tested in Unreal Engine 5.8

## Tech Stack

- **Engine:** Unreal Engine 5.8
- **Language:** C++

## Getting Started

### Prerequisites

- Unreal Engine 5.8
- Visual Studio (or your preferred IDE with UE5 support)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/battle-blasters.git
   ```
2. Right-click the `.uproject` file and select **Generate Visual Studio project files**
3. Open the generated `.sln` file or the `.uproject` file directly in Unreal Engine
4. Build and run
